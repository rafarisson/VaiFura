# VaiFura

A lightweight application for processing PCB drill and profile files, focused on a simple workflow for generating G-code.  
Built with Qt (QML/C++).

## Features

- Import drill files:
  - Excellon (`.xln`, `.drl`, `.txt`)
- Import board profile:
  - Gerber (`.gbr`)
- Drilling path optimization
- Generate G-code
